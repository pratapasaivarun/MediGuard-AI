# Fictional evaluation dataset

This folder contains the committed hand-calculated benchmark labels, thirty generated fictional case folders, their bill/policy/settlement PDFs, a separate set of thirty manually labeled retrieval questions, and a synthetic category challenge set (`category_benchmark.json`). Bill line descriptions are specific fictional service names so category extraction can be evaluated. `python -m evaluation.generate_cases` recreates only the document fixtures from the committed labels; it never edits expected results. The PDFs and category challenge are test material, not real insurance documents.
